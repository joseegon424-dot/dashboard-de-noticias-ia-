# Dashboard Layout SOP

## Estructura Visual

```
┌──────────┬────────────────────────────────────────┐
│          │  HEADER (título + búsqueda + status)   │
│          ├────────────────────────────────────────┤
│ SIDEBAR  │  STATS BAR (4 tarjetas métricas)      │
│  - Logo  ├────────────────────────────────────────┤
│  - Nav   │                                        │
│  - Fuent │  ARTICLES GRID (cards responsive)      │
│  - Refre │                                        │
│          │                                        │
└──────────┴────────────────────────────────────────┘
```

## Marca: COGNISIUM LAB
- **Primary:** #00FF88 (verde neón)
- **Background:** #020403 (negro profundo)
- **Font:** Inter (todos los pesos)
- **Efectos:** Glassmorphism, glow verde, backdrop-filter blur

## Breakpoints
| Breakpoint | Layout |
|---|---|
| > 1024px | Sidebar fija + grid 3 columnas |
| 768-1024 | Sidebar fija + grid 2 columnas |
| < 768px | Sidebar oculta (toggle) + grid 1 columna |
